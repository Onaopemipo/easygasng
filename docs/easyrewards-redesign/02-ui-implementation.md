# EasyRewards UI

The existing customer account shell hosts the redesigned `/rewards` page. The balance, programme and offer panels use the active account’s data. The small referral form opens in a contextual dialog on desktop and a sheet on mobile web and native. Existing icons take the place of decorative gift art. The layout reflows for narrow viewports and uses the existing appearance preference and tokens.

Points history starts with six entries and reveals 20 more at a time from the same summary. The server returns up to 200. The web links use the existing order and booking destinations. Native opens an order by ID and uses the existing service bookings list for a linked appointment.

The native screen is available in the customer account and home navigation. It reuses the existing checkout selection and existing referral endpoints. Both clients load rewards independently of the wallet and refresh confirmed data after returning to the app or page.
