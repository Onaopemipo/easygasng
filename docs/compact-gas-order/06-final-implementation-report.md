# Gas order redesign

The compact form, backend-priced summary, order review and native parity changes are implemented locally. No production settings or records were edited. Production remains NO-GO and no deployment was made.

The mockup's cylinder chooser is guidance, with a supported capacity retained in each payload because the current backend requires it. On small screens, the summary follows the form in document flow. The native review remains within the customer order screen using the existing form and payment options.
