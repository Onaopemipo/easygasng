# Design implementation

- GAS-001 and GAS-002 use the existing public header and artwork. The order form is centred with a compact sticky summary on taller desktops and a single-column layout on smaller screens. The demo notice sits above the content.
- GAS-003 uses the existing native shell. Its summary distinguishes estimated and quoted amounts, provides an explicit review action, and collapses the size guide.
- GAS-004 shows supported capacity tiles, decimal input, policy-valid step and preset controls, and additional cylinder lines.
- GAS-005 keeps location and address visible, keeps saved addresses available, and opens secondary details when a required field is invalid.
- GAS-006 keeps existing date, delivery window, rewards and payment controls, and adds an itemised server quote and edit shortcuts.
- GAS-007 keeps existing success, payment and tracking destinations.
- GAS-008 surfaces pending coverage, unavailable pricing, stale quote input, and retry.
