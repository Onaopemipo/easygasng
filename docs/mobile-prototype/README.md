# EasyGas mobile app review

[Open the private mobile prototype](https://easygas-complete-experience.philipmuyiwa.chatgpt.site). Sign in with the owning ChatGPT account, then use **Review controls** to choose Customer, Business owner, Service Manager, Inventory, Driver or Technician. Visitor entry screens are also available.

The app uses bottom tabs, back controls, contextual sheets and native app components. There are 117 role/screen entries and five shared journeys. Twenty proposed workspaces fill current browser handoffs; each is clearly labelled **Proposed mobile screen**.

1. Explore a role with the app controls or the screen directory.
2. Choose **Journeys** for delivery, service, refund, approvals or stock/custody. The guide simulates each step and shows the shared reference/readback.
3. Try rejected payment or expired calibration from the delivery scenario selector.
4. Use **Reset mobile prototype** to restore only the local example data.

All data is synthetic and local. Some forms are interaction previews. Phone-frame choices are review modes, not installed iOS/Android builds. Production NO-GO/import/retain-all decisions remain.
