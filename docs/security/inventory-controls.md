# Inventory integrity controls

Authoritative stock remains `inventory` + append-only `stock_movements` for physical units, and `gas_stock` + append-only `gas_stock_movements` for integer grams. New receipt/hold/operation records are evidence and unsaleable condition metadata, not competing saleable balances. Existing checkout, POS, service material reconciliation, cylinder allocations and delivery/cancellation paths remain authoritative.

- **Receipts:** scoped stock roles, active branch/product, positive integer units or maximum-three-decimal kg, explicit passed receiving checks, actual delivery date and reason/evidence. Supplier must belong to branch. Linked purchases must match product/unit/cost/supplier and current independent approval authority. Partial receipt cannot exceed remaining quantity. Unique receipt reference prevents double credit; changed replay conflicts. Uncosted legacy receipts remain supported for physical goods and make valuation unavailable. Fixed-size refill unit receipts are rejected.
- **Adjustments and stocktakes:** record observed quantity/reservations and signed delta or actual count, reason/evidence/reference. Shared approval creates no immediate stock change. Independent activation locks/revalidates exact balances and reservations; stale counts fail with no movement. Unique operation reference and applied-once request protect replay. Failure preserves the review and supports governed retry only if current facts remain valid; otherwise cancel and recount. Stocktake sessions select branch/category and optional bulk gas, capture authoritative snapshots, generate audited count sheets, require every selected item once and submit per-item variances through shared approvals. Movements during the count reject submission and require recount/reconciliation; all approved variances close the session. Per-product correction remains available.
- **Quarantine:** immediate protective removal of unreserved saleable quantity, immutable movement, separate held quantity and audit. Reserved unsafe goods require the original order/service cancellation or safety intervention rather than silently consuming their reservations. Hold release requires documented condition evidence, current independently verified `inventory_safety` qualification at request and activation, independent owner approval and enough unreleased held stock.
- **Returns:** physically recovered customer goods enter hold; never automatically saleable. Cancellation only releases original reservations. Technician unused materials use their original service job reconciliation. Supplier returns/write-offs consume already-held goods through an approved disposition, create a zero-balance movement and preserve evidence; they do not deduct twice. Serialised cylinders cannot use generic release/disposition/transfer; use existing custody/inspection procedures. There is no invented bulk-gas recovery or automatic refund-to-stock rule.
- **Transfers:** existing `stock_transfers` now requested → approved/reserved → dispatched/in_transit → partial receipt → received or discrepancy. Approval checks available stock; dispatch rechecks active requester/owner authority. Source reserves then deducts once; destination independently verifies bounded good/damaged quantities under its own branch authority. Damage enters hold. Partial/unresolved quantities remain visible, never silently disappear. Cancellation releases an undispatched reservation; dispatched returns require physical reconciliation. Current implementation disables generic cylinder transfers until an approved serial-by-serial procedure exists.
- **Cylinder release:** existing inspection records/custody retained. A passed inspection requires fresh verification and a current independently verified `cylinder_inspection` qualification. It marks empty, never full or certified by assumption. Existing allocation, quarantine, expiry, sale custody and fill checks remain in force.
- **Costs:** receipt acquisition costs are append-only and independent from selling price. Valuation requires an approved `inventory.valuation=weighted_average` method and a complete movement cost basis. Unknown opening stock, uncosted receipts/returns/transfers return unavailable; no sale-price substitution. Inventory totals never combine kg with units. Profit still needs recorded COGS/labour/overhead reconciliation.
- **Export/recovery:** report generation rechecks current role/branch and logs exports; CSV escaping and XML/HTML encoding reuse existing report helpers. Operators correct with a new approved operation; historical movement/evidence rows cannot be edited or deleted by ordinary application roles.

See `inventory-finance-permissions.md`, `../testing/inventory-finance-security-tests.md` and the verification report. Independent PostgreSQL race acceptance remains blocked; PGlite serialisation is not multi-connection evidence.
