# Delivery location management

Lagos Island, Victoria Island, Lekki and Ajah are initial active, visible database records. Locations have stable IDs, city/state/country, a fulfilment branch, active/visible/archived flags, display order, coverage description, customer description, version and timestamps. They are managed in Admin → Settings → Delivery Locations. The gas/delivery management disclosure also offers Add delivery location. New records remain inactive while their requested configuration awaits independent owner approval.

Editing, activation, deactivation, archiving and display-order changes submit the existing setting key `location.<id>` through the shared Approval Centre. There is no direct location activation endpoint. Archive requires inactive and hidden flags. A location is permanently associated with its request branch; creating coverage for another branch requires an authorised request in that branch, preserving history and branch access.

A location name does not prove that a street is serviceable. New ordering requires a business-confirmed coverage description. Locations default to staff confirmation of each actual address before gas dispatch. Owner-approved configuration can explicitly cover the entire named area. Manual confirmation records the reviewed order address, current location version, actor and evidence in append-only audit history. A material location version change invalidates old confirmation. No geocoder, polygon validation or GPS certainty is fabricated; staff must verify precise boundaries manually under the configured policy.

Only active, visible records at active branches are offered for new selection. New orders are rejected for inactive coverage. Addresses remain saved and are labelled unavailable; existing orders retain their location and address snapshots and receive an operational-review flag. They are not cancelled automatically. An owner must review fulfilment after withdrawal of a location. Historical location grouping uses the stored order snapshot. Location management shows real order and delivery counts; the gas report filters by stable location ID.
