# Admin approvals

Admin approval is final. You do not need another Admin or Finance colleague to approve your request.

1. Open the existing setting or operation, enter the details and select its review/confirmation action.
2. Check the summary, then confirm once. If prompted, verify your own password.
3. The result is applied immediately, scheduled for the selected date, or explains the evidence/version issue that prevents activation. Audit History records the action.

For an existing pending request, open **Approval Centre**, select it and choose **Approve** once. Drafts must first be submitted. Other staff requests also complete with one Admin approval.

A staff invitation must first be accepted by its recipient. Its access plan then needs one Admin approval. An Admin can grant another existing staff member access directly through Staff Management. You cannot change your own privileges.

A request's approval does not invent actual payment receipts, LPG measurements, delivery photos, customer agreement or qualification evidence. Complete those records when the workflow asks for them. If an authorised change fails to activate, fix the displayed cause and retry it; another approver is not required.

These rules are available on the demo with migration085. The current hosted audit and any remaining release gates are tracked in the requirements matrix.
