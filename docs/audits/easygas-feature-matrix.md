## Interpretation

The large number of partial/unverified entries is deliberate: existing API tests do not prove complete frontend behavior, physical workflows, external providers or actual native devices. In particular, “Wallet”, “Subscriptions”, “Notifications”, “Cylinders” and a “Commercial” role must not be interpreted as complete financial, delivery, safety or B2B modules.

No implementation percentage is given: the requirements contain overlapping features and optional additions, and a percentage would conceal their different risk and scope. See the verification report for commands/results and security report for reproducible findings.
