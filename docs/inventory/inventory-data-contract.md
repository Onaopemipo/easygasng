# Inventory data contract

Canonical eligible stock is inventory.quantity/reserved (integer units) and gas_stock.grams/reserved_grams (integer grams, displayed kg to3 decimals). Held quantities in stock_holds have already been removed from eligible projections by quarantine/return/transfer-damage workflows. Physical on-hand shown here = eligible+outstanding hold; available=eligible-reserved. Never subtract held twice. Totals sum integers in SQL before kg conversion; kg is never added to units. In-transit transfers remain separate from destination availability.

The new inventory-workspace.ts is a derived read facade, not a new balance or ledger. It uses the existing inventory, products, branches, gas_stock, stock_holds, stock_movements, gas_stock_movements, inventory_operations/change_requests and valuation service. Inventory categories exclude Gas refills: gas content is gas_stock; cylinder vessels remain product units. Serialized cylinders are not added to the product-unit total again. A displayed vessel count is not a certificate of eligible serial custody/inspection. Actual configured bundle components remain under existing fulfilment rules; the legacy kit SKU represents its existing independent physical inventory, not newly manufactured component stock.

Sidebar reorder count: physical eligible-reserved<=threshold, active catalogue records excluding Gas refills, plus gas with configured threshold and available<=threshold. It includes zero quantities. Workspace shortage uses the identical condition in the selected branch; sidebar owner scope remains all authorised navigation branches. Positive low and zero out-of-stock are separate conditions. Gas without a threshold can be out of stock without contributing a reorder alert. Pending inventory approvals are separate, unexpired unapplied requests.

Cards and bulk balances describe selected branch scope BEFORE row filters. Category counts are stock records, not physical-unit quantities:8 physical SKU records plus1 bulk gas record in the current isolated demo;0units/0kg remain real. Missing threshold is Unconfigured, not0. Reserved and held columns have explicit units.

Valuation reuses inventory-valuation.ts moving weighted average only after independent policy approval and complete acquisition-cost movements/opening basis. Owner/finance only; retail prices never substituted. Eligible stock value excludes held valuation because its acquisition basis is not fully modeled. Complete eligible valuations reconcile to category sums; zero value shows no positive stock. Incomplete/unconfigured/restricted costs return Unavailable with a reason. Ageing/turnover/shrinkage and barcode/serial search are not invented.

Stock rows20/page, page1–10000, query<=100, closed sort/status/category enums, parameterized literal LIKE. Movements20/page, Lagos date filters, maximum367-day explicit range, immutable references/actors/units. Export<=5000 matching rows or fail without partial output; no cost/private-customer columns. Per-user HTTP budgets120 reads/min and6 exports/min. Canonical session/branch authorization is current per request; dashboard/history reads are repeatable-read read-only transactions. Export audit is transactional in its ordinary existing dispatch boundary.
