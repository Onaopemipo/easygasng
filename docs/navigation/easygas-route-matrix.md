Owner browser QA verified every route in all three modes. Module headings loaded without error notices; active state matched exactly. The independent business regression suite covers existing operations, not a claim that every CRUD action was repeated manually on every page. Seven representative role experiences were checked in browser; every existing staff role’s permitted read actions and restricted-runtime aggregates were exercised by automated tests.

Driver navigation is restricted to assigned Deliveries; technician navigation to assigned Bookings and Professional Services. Their native mobile navigation is unchanged. Empty groups are omitted. Expanded groups, compact icons and the drawer use the same source; compact icons remain directly reachable with labels on focus, rather than disappearing when groups collapse. `scope` describes the route context; actual row filtering remains in each existing API. Owners may have global read scope, while branch-restricted readers retain assigned scope. Audit History retains the existing owner/technical-administrator global read allowlist.
