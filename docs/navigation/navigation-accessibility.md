# Navigation accessibility verification

Navigation uses an aside, labelled navigation landmark and labelled group regions. Icons are decorative; links retain full accessible names in every mode. The active route uses `aria-current=page` plus a green background/indicator. Group buttons expose `aria-expanded` and `aria-controls`; closed content is inert. Compact focus/hover labels use a tooltip associated with the active link. The account disclosure and sign-out action remain accessible.

Mobile navigation exposes a named modal dialog, makes background content inert, locks body scrolling and traps Tab/Shift+Tab within visible, enabled controls. Close button receives initial focus, with a bounded retry after the visibility transition (background tabs can pause animation frames). Escape, backdrop, close button and route selection dismiss it; focus returns to the initiating control. Keyboard checks verified both wrap directions and Escape restoration. Group controls were tested with Space and Enter for all six collapsible groups. Visible focus outlines are 2px green with a 2px offset. Screen-reader names, states and active selection were inspected in the accessibility tree/DOM. No VoiceOver spoken-output or cross-device certification is claimed.

Text/control labels retain the user's 15px minimum. Navigation rows and mobile controls provide at least 44px touch targets. Longer labels wrap where needed, without squeezing icons or badges. The compact badge becomes a coloured dot, while the accessible name retains its exact count and meaning. Text is never reduced to fit a long menu item.

Reduced motion was exercised using the OS preference: sidebar, group and workspace transitions changed to `0s`; after restoring the original off preference, they returned to the configured 240ms/200ms settings. The original OS preference was restored. The loaded browser stylesheet also confirms the reduced-motion media rule disables transitions and smooth scrolling. Normal configured transitions: sidebar 240ms, groups 200ms/180ms, hover 120ms. These settings are separate from measured automation acknowledgement latency.

The palette calculation in `docs/testing/navigation-contrast-20261030.json` checks ordinary/group/active text, muted role text, attention/ordinary badges and the focus outline. Minimum sampled contrast is 4.82:1, above the 4.5:1 normal-text threshold. Brand imagery and disabled loading controls are excluded from this text sample. This is a focused navigation verification, not a platform-wide WCAG certificate.
