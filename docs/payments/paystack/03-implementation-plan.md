1. Preserve repository and baseline; map current money/identity/stock authorities.
2. Record official provider sources and merchant-specific blockers; default OFF/sandbox only.
3. Integer fee policy and smallest-gross solver, including discontinuous waiver boundaries; comprehensive deterministic tests.
4. Typed hosted Paystack adapter and signature verification with timeout/URL/key/environment constraints; no card collection.
5. Additive attempts/immutable quotes/events/postings/exceptions using current users/orders/invoices/service/wallet ledgers. External HTTPS outside database transaction; prepare/finalise with stable references.
6. Provider verify followed by locked, exactly-once canonical posting and existing notifications; durable signed receipt inbox + worker reconciliation.
7. Existing invoice/web/native/payment-request/wallet/service/amendment integration, explicit fee acceptance and guarded UI.
8. Independent provider refund approval/status/reversal and reporting, no double credit or fabricated payout.
9. PostgreSQL concurrency/security/regression, official sandbox E2E when configured, restore/recovery and independent sign-offs. No live activation.

Scope is the complete supplied specification. Foundations alone are not full end-to-end acceptance; blockers and unfinished engineering must remain separately labelled.
