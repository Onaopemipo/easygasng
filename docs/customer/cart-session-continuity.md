# Cart, address and session continuity

There is still one easygas.cart localStorage cart and one Site shopping context. Cart contents are product identifiers/quantities only, never credentials or private account records. Safe parsing rejects malformed rows, invalid quantities and duplicate product IDs. The same cart is reused for guests and signed-in customers; no independent server guest-merge or duplicate customer-cart store was introduced. Existing checkout remains authoritative for stock/prices/location/capacity and idempotency.

Ordinary dashboard/public navigation does not clear the cart. Cart mutations persist after hydration and cross-tab cart changes update the existing context. Login does not add or duplicate items. Logout clears private session drafts while retaining the non-sensitive product cart. Browser QA verified one synthetic Gas Hose through dashboard/home/cart, logout, guest sign-in and restoration of /checkout at quantity1.

Delivery location comes from the active owned default saved address; unavailable locations are excluded from default indicators and disabled for new address selection. Customers use the existing Account & Privacy address workflow to select an active backend-managed default. Gas ordering and physical checkout now initially populate that owned available default. Its recipient/street/phone remain protected; the header shows the location name. Backend eligibility is still checked at order time.

Existing session drafts are retained where supported. The gas sign-in link saves the unfinished gas lines/address/date/window/method in sessionStorage, restores the allowed gas-order return destination and obtains a fresh quotation; draft values never establish price or eligibility. Logout clears these private drafts. Existing physical checkout idempotency and pendingCheckout handling remain unchanged. Browser QA did not submit a new order because the test configuration intentionally disabled ordering/payment methods; existing checkout regression tests cover authoritative validations. No payment provider was enabled.
