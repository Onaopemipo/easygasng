# Security and permissions

Existing invoice/PDF handlers recheck customer ownership and staff role/branch, require fresh finance verification for issue and preserve immutable DB records. Receipts join committed provider postings; unknown/pending IDs404. `documents.list` allows customers/commercial own records and owner/finance authorised scope only; no driver/technician escalation, arbitrary customer override or public invoice object URL. Strict inputs, literal parameterized search, complete scoped counts,20-record page bound, Africa/Lagos date range. Projections return presentation data, not internal service/material acquisition prices or provider secrets. Reads are audited without copying full documents into audit detail.

Approved note downloads recheck original invoice authority and actual approved note membership, format filename from safe stored identifiers and return private/no-store PDF headers. Foreign or pending note404. Existing receipt endpoint uses the same no-store/attachment controls. React escapes identity/customer/reference strings; PDF treats strings as text, never HTML. Trusted local asset paths only. Cache holds embedded fonts; no cached private document data. Native downloads require existing bearer auth and use randomized temporary filename deleted after sharing, with no new offline plaintext retention.

New `document.identity` is a risk3 owner proposal + independent owner/finance approval through the shared workflow, with fresh verification/evidence and versioning. Format validation rejects markup, credentials in website URLs, invalid email/phone, empty evidence and unsupported compliance flags. Actual registration/tax authenticity requires business/legal review; code does not certify compliance.

Paystack signature/exact amount/currency/environment/identity verification and exactly-once ledger constraints remain unchanged. No real merchant request, refund, external message, live credential activation, backfill or hosted deployment is performed. Existing retain-all, Excel import hold, automatic dispatch OFF, deferred native/server work and production NO-GO remain.
