# Privacy and security

Location is for active deliveries, keyed to committed, consented GPS observations. Customers receive one eligible observation with its expiry and source, while authorised dispatchers can see the last observation during active stops. Withdrawal and trip close stop fresh publication. Staff requests are branch-scoped and audited without raw coordinates in the audit detail. No background location is shown to other customers or published on a public feed.

The optional map sends location context to Google when opened. The existing external Google Maps link is also an explicit user action. Review this transfer, retention schedule, driver notice, incident response and Nigeria-specific obligations with the responsible privacy and operations teams before activation. The existing retain-all decision applies to business records. No history is deleted by this phase.
