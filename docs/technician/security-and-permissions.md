# Technician security
technician.login uses canonical credentials/throttle/session issuance and rejects non-technician identities. technician.restrict scopes an existing session; actor reads the capability from the verified session row. The API allowlist excludes approval decisions, cash collection/verification, finance, delivery, sales and unrestricted stock. Direct service start, material issue/use and successful report share serviceWorkAuthority, independent of button state. Booking access rechecks assignment/branch; restricted reads recheck qualifications. Suspension revokes actor access.

Generic quotation review remains assigned/current-quote scoped for technicians. Independent owner approval and customer acceptance are separate. No mobile-supplied paid flag or quote price can bypass the guard. Stable HTTP mutation IDs are required; canonical booking locking and operation-result receipts preserve exactly-once effects. PostgreSQL TECH-T56 verifies concurrent denied unpaid starts and one event from duplicate paid starts.
