# EasyGas test-store build notes

Target: unified EasyGas Android app and iOS/iPadOS app, version 0.1.0. This phase uses the existing website backend at https://easygas-client-demo.vercel.app with synthetic demo records. Commercial production remains NO-GO.

Test the existing role-specific flows for Customer, Commercial customer, Admin/owner, Service Manager, Inventory/finance, Driver and Technician using the labelled QA accounts. Verify full-width layouts on phones/tablets, safe keyboard clearance, long-page scrolling, transparent logos in light/dark appearance, and navigation/logout.

Recheck Manager Dispatch access-loading, denied/retry and empty states; purpose-specific Dispatch/Customers/POS icons; and confirmations above full-screen forms (Keep editing, Close form and back cancellation). Existing server role, branch, password, approval, qualification, trip, payment and stock requirements still apply. Missing provider permissions/certification must remain visible rather than be treated as completed.

These test binaries do not certify physical delivery/safety, commercial policies, real providers or all 300 native feature leaves. Do not treat a synthetic QA renewal or a beta-store upload as production approval.

Android testers can [join the internal test](https://play.google.com/apps/internaltest/4701444205316057539) with an account from the existing AfriMarket Pilot Testers list. Apple testers should open TestFlight using the same account used for AfriMarket; EasyGas Energy Solutions version0.1.0(2) is assigned to the matching two internal testers. Testing/distribution in France is excluded by the owner-approved declaration.
