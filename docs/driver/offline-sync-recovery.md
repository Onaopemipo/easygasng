# Offline recovery
The existing encrypted per-user field queue stores proof and mutation intent. Stable operation keys survive uncertain responses. Sync checks committed-operation receipts first, then current ownership, attempt and version. Conflicts retain encrypted evidence and stop dependent work for that order. Independent orders may continue. Transport/auth failures retain pending records. No offline action is represented as server-delivered. Legacy cash completion records remain retained for dispatch review and are never replayed by this workspace. Physical-device crash, reinstall, storage exhaustion and concurrency acceptance remains outstanding.
