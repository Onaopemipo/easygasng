# Private proof
Capture requires explicit consent and a description. Camera permission is requested on use in the dedicated driver shell. Gallery is disabled unless the server approval flag is enabled. Evidence uses the existing private photo upload endpoint and encrypted queue. Completion checks current driver, branch, latest attempt, arrived state, retained nonempty private evidence, verified wallet payment, OTP, handover and canonical version. Photo capture alone never completes delivery. Existing historical evidence is not overwritten by retake. Private history viewer is implemented with authenticated image requests; real-device permission/retention acceptance remains unfinished.
