Latest EasyGas ordering and driver workflow updates.

Customer:
• Sign in, create an account and recover access using the updated authentication screens.
• Place a gas order, confirm the delivery address and map pin, review the current price and pay.
• Save contact/address details when offered. Use Order again from a previous order and review the fresh checkout, quantity, delivery date and payment before submitting.
• Phone orders appear on the customer profile for payment; every phone order must be paid before confirmation, including an extra order with no additional delivery fee during the same visit.

Driver and technician:
• Accept an assignment directly without typing an acknowledgement reason.
• Review the readable vehicle gas allocation, confirm the actual load is ready and start delivery in one action.
• Open directions to the confirmed destination, record arrival, enter the actual supplied amount and add the required photo evidence to complete the order.
• Check an extra paid order assigned during an existing trip. Required payment, vehicle custody, delivery proof and reconciliation checks remain in place.

Business (web Dispatch using the same testing backend):
• Follow the setup checklist, assign a branch vehicle to a driver, select a ready driver and resolve order-level blockers using the provided actions.
• End or change a vehicle only after the required trip reconciliation checks.

This build uses the existing synthetic client-demo backend. TestFlight distribution does not activate live providers or imply full physical-device, background tracking, camera/push, accessibility or commercial production acceptance.
