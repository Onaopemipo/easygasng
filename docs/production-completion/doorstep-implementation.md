# Doorstep gas execution continuation — PARTIAL / production NO-GO

8 November 2026. Extends E2E-01 and BULK-R08. All previous requirements, scenarios/gates and the actual Excel import hold remain. This does not complete the full production request.

## Implemented operating flow

1. Assigned driver proposes exact gas quantity/capacity and current governed price for the original visit. The signed-in original customer sees quantities, price and zero additional delivery fee before recording consent. Proposal/consent history remains protected. The scoped driver app uses the gas-only adapter, not a generic sales endpoint.
2. Qualified inventory staff, with recent password verification, inspect an existing empty customer-owned cylinder and record safe allowance/evidence. Preparation requires the current arrived attempt, unchanged order version, acknowledged vehicle buffer, active suitable branch/vehicle, current driver qualification/calibrated meter, original settled issued invoice, current unchanged price/policy and a proposal younger than15 minutes. No duplicate existing refill/cylinder or other pending supplement is allowed.
3. In one transaction, measured grams transfer from vehicle buffer to protected supplementary custody without increasing branch reservations. A fixed-price pending debit note is attached to the existing invoice. Original order, issued invoice snapshot, delivery fee and gas lines are unchanged. Existing invoice-note approval requires an independent owner/finance decision; preparation does not itself approve or post payment.
4. The driver reports only exact additional cash actually collected, after debit approval. Independent recently verified finance/owner reconciles that report into the existing immutable verified_payments ledger once. Browser/mobile return, driver report or a screenshot never establishes settlement. Finance may reconcile cash already reported within validity after expiry/meter retirement; that does not authorise physical dispensing. Changed obligations/duplicate settlement remain finance exceptions requiring review.
5. Before metered dispensing, backend rechecks assignment/version, unexpired consent, unchanged price/policy, original address/cylinder eligibility, current qualifications, meter, vehicle, supplementary cylinder custody and full current invoice settlement. Cumulative meter delta must exactly equal reserved supplementary grams. Canonical branch mass/reservation, vehicle meter/custody, cylinder state and immutable movements/events change in one transaction. An operation receipt protects exact retries.
6. The original visit completes through its existing customer code, proof-photo, arrival and full-handover controls. Only fulfilled, settled supplementary debits are accepted by the original invoice/fulfilment reconciliation check. Scoped native completion now accepts previously independently verified COD, with the matching original driver's reconciled collection and settled invoice; it cannot create or verify cash. Original payment_status remains verified. No new order, customer or extra delivery fee is created.

Existing web order and bulk-delivery panels share controls; existing customer/driver mobile visit views show actual quantities, amount, debit and execution state. Menus/onboarding remain unchanged. Finance reviews debit notes through existing invoice controls. User-visible invoice/statement output retains original total, approved notes and effective balance; credit balance is now explicitly returned from the authoritative invoice balance.

## Cancellation and exceptions

Pending debit must first be independently rejected, or an approved debit must receive an independently approved exact credit on the same invoice. Only undispensed mass returns to vehicle buffer; branch reservations are not prematurely released. Original consent/observations and approved money records are retained. Paid cancellation leaves an explicit credit balance for separate finance refund reconciliation; it never fabricates a refund. Unreconciled physically reported cash is held for finance review before cancellation.

Parent fulfilment, cancellation and load return cannot strand reserved supplementary gas. Dispensed gas cannot be restored by order cancellation. Missing/expired/changed consent, safety, calibration, stock, quote, invoice or payment evidence rejects dispensing and preserves records for review. No offline success or automatic financial replay is claimed. The driver must refresh current visit state after an unknown outcome; physical/private-device recovery acceptance remains open.
