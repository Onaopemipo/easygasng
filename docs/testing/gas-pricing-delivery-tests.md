# Gas pricing and delivery verification

Run `npm test` for isolated synthetic PGlite tests, `npm run typecheck`, `npm run typecheck --prefix apps/mobile`, and `EASYGAS_PREVIEW=true npm run build`. Native bundle verification uses `cd apps/mobile && npx expo export --platform ios --platform android --output-dir <temporary-output>`. Do not build `.next-qa` while the isolated QA dev server uses it.

`tests/shared-approval-gas.test.ts` covers draft submission, denied roles and forged status fields, self-approval, distinct dual decisions, revised approval invalidation, schedule preservation, stale versions, duplicate activation, failure/savepoint recovery, retry, rollback, fee rejection, expiry, revoked authority, decimal examples, multiple cylinders, one fee across all four areas, inactive locations, saved/default addresses, stock reservation/cancellation, physical cylinder intake/quarantine/inspection, verified delivery, cash remaining unverified, reporting and export injection protection. Existing safety, branch, wallet, serial allocation, service and custody regressions remain in the full suite.

The latest final result and exact logs are recorded in [the implementation report](../reports/easygas-gas-pricing-delivery-implementation.md). No coverage percentage is inferred. Some original fixed-refill commerce tests now exercise a physical accessory to retain their unit-stock/payment regression purpose; gas-specific tests exercise the new gram-based path. Historical test records and supplied catalogue prices remain tested separately. Fee fixtures explicitly set their own synthetic regression value; the business initial fee is tested as 500,000 kobo.

A separate test `tests/postgres-approval-concurrency.test.ts` requires an explicitly enabled disposable local PostgreSQL database. Supply `EASYGAS_TEST_POSTGRES_URL` for a localhost database named `easygas_test…` and set `EASYGAS_ENABLE_LOCAL_PG_TESTS=yes`; leave `DATABASE_URL` unset. The harness creates and removes only a uniquely named test schema and opens multiple pooled connections. It exercises competing approvals, duplicate activation and final-stock reservation. No such instance is configured here, so this test is skipped, not passed. Automatic review rejected an earlier unconstrained database command before execution; the replacement harness restricts destinations and remains disabled by default.

Browser QA uses `.data/services-browser-qa-20261030` with synthetic accounts only. It verified draft creation/edit/submit/withdraw, absent own-approval controls, unchanged active price, multiple-cylinder estimate NGN 24,800, the size guide, initial locations, disabled ordering for missing configuration, report execution and CSV download. Five affected pages were measured at 1280 and 390 pixels with a 16px minimum and no page-level overflow. Native physical-device, signed distribution, accessibility sizing and real PostgreSQL concurrency are not claimed as verified.
