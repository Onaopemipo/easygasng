# Security and privacy

The server scopes driver reads to the authenticated role, assignment and active branch. A restricted driver session cannot access wallet, finance or staff dispatch. History excludes customer contact details and never exposes another driver's attempts. Evidence downloads continue to require ownership and the existing private-media policy, with optional narrowing to the closed attempt. Originals, retention and consent rules remain in force.

Availability and assignment responses use existing authenticated, idempotent actions. Payment, stock, cylinder custody and inspected pickup checks still run on the server. Location capture uses the existing trip consent and device permissions. Browser disconnection disables state changes and labels the displayed records as stale. Native pending actions are never treated as committed merely because they enter the local queue.
