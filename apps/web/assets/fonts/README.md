# Invoice font

Noto Sans Regular, distributed under the included SIL Open Font License. Embedded locally in invoice PDFs so names with Latin diacritics and the naira sign remain readable; no remote assets are fetched while serving invoices.

Source: https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf . Downloaded 5 November 2026. Retain OFL.txt when redistributing. Unsupported characters are represented explicitly by their Unicode code point rather than silently omitted.

Noto Sans Bold added9November2026 from the bundled LibreOffice font distribution (same Noto SIL OFL); locally embedded subset for financial-document heading weight. Both fonts are covered by the included OFL; no standalone user font download is exposed.
